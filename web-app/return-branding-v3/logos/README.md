# Logos

The mark is a sun on the horizon with its reflection on still water. The wordmark is "return" in Instrument Serif italic, outlined. It stays in that open-licensed face on purpose: the display fonts (Role Model, Rusilla Serif) are personal-use demos, and a logo needs a font you can use commercially.

- `return-lockup-ink.svg`: mark plus wordmark in `ink` (#141a2b). On canvas, plain surfaces and day glass (GlassNav in day).
- `return-lockup-white.svg`: the same in white (#ffffff). On dusk glass and directly on scrimmed imagery.
- `return-mark-ink.svg` / `return-mark-white.svg`: the sun alone, same inks. Favicon, Quest app tile, small spaces, brand-center nav.
- `return-wordmark-ink.svg` / `return-wordmark-white.svg`: the word alone, for places the mark already appears.

Each file has one fixed ink (an `<img>` can't inherit `currentColor`). Minimum size: 20px tall for the mark, 24px for the lockup.
