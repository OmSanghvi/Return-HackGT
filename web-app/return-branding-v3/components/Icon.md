# Icon

Line icons for return: 23 glyphs plus a spinner on a 24px grid, 1.5 stroke, round caps and joins, drawn in `currentColor`.

Props: `name` (see `Icon.names`), `size` (default 20), `strokeWidth`, `label`. Without `label` the icon is decorative and hidden from screen readers; add a `label` only when it stands alone and carries meaning.

- 14px in chips, 16 to 18px in buttons, 20px in lists, 22 to 24px in VR.
- Don't fill icons (play is the one exception), mix icon sets, or use emoji.
